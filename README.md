# Home Bills Manager 🏠🌿

A modern, responsive household bill management application built with **React, Vite, and Firebase**.

Track and manage monthly bills, monitor expenses, set custom budgets, receive budget alerts, and download bill reports in PDF format.

### Features
- Monthly expense dashboard and charts
- Add, edit, delete, and track bills
- Custom monthly budgets and spending alerts
- Firebase Authentication and Firestore database
- PDF reports and bill history
- Responsive design for mobile and desktop
- PWA support for installation on mobile devices

### Tech Stack
React • Vite • Firebase • Cloud Firestore • PWA
